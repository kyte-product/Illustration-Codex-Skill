    A few questions
    before you begin

    What is an illustration skill?+

    A skill is a set of instructions that helps Codex handle a task. Each style skill describes its shapes, colors, materials, and lighting so related icons keep a consistent look.

    How do I install these skills?+

    Download the illustration-icon-skills.zip from this project and ask Codex to install it, or copy the folders inside skills/ to your Codex skills directory.

    How do I use the wizard?+

    Say “Use illustration-icon-wizard.” Answer one question at a time. Say back to revise the previous choice or default to accept the current suggestion.

    Can I call a style directly?+

    Yes. For example, say “Use flare-icon.” It skips the style picker and asks about the remaining choices one by one.

    Can I add a style from a reference image?+

    Yes. Share the image and ask Codex to study its shape language, surfaces, lighting, palette, and level of detail. The new style can be added to the collection as a standalone skill.
